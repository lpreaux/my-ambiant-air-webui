# My Ambiant Air — interface web (projet de formation QUALAIR)

> Prototype pédagogique non maintenu, conservé pour documenter le démarrage du projet de formation QUALAIR.

Socle d'interface créé avec Angular 17, Tailwind CSS et Leaflet. Le dépôt est resté au stade de l'initialisation : il ne contient pas encore les écrans fonctionnels du produit.

## Lancement local

Prérequis : Node.js 20+ et npm.

```bash
npm ci
npm start
```

Ouvrez ensuite <http://localhost:4200>. Les commandes utiles sont :

```bash
npm run build
npm test
npm run lint
```

Une ancienne révision contenait une configuration d'API directement dans le code. La branche courante n'en contient plus ; toute clé historique doit néanmoins être rotatée et purgée de l'historique Git avant une nouvelle publication.
